### Desktop version
1. Clone the repository:
    ```
    $ git clone git@gitlab.ecs.vuw.ac.nz:course-work/engr301/2026/project1/team5/shopwise.git
    ```
    or if you havent set-up your SSH key:
    ```
    $ git clone https://gitlab.ecs.vuw.ac.nz/course-work/engr301/2026/project1/team5/shopwise.git
    ```
2. Enter the project directory:
    ```
    $ cd shopwise
    ```
3. Compile and run the program:
    ```
    $ cargo run
    ```
